    Endpoint Matrix

    POST /reset

    Start a new episode and receive the first observation state.

    POST /step

    Submit a single agent action payload and receive reward + next observation.

    GET /state

    Read the complete current session snapshot, including latest reward metadata.

    GET /tasks

    List available tasks with hints and difficulty metadata.

    GET /health

    Probe API readiness and version response payload.

    cURL Runbook

    # Set your Space URL
        export SPACE_URL="https://lazerai-meddataops.hf.space"

# Health + task list
curl -s "$SPACE_URL/health"
curl -s "$SPACE_URL/tasks"

# Reset and capture session
SESSION_ID=$(curl -si -X POST "$SPACE_URL/reset" \
  -H "Content-Type: application/json" \
  -d '{"task_id":"triage_report"}' | sed -n 's/^X-Session-Id: //p' | tr -d '\r')

# Submit one action
curl -s -X POST "$SPACE_URL/step" \
  -H "Content-Type: application/json" \
  -H "X-Session-Id: $SESSION_ID" \
  -d '{"action_type":"submit","parameters":{}}'

# Read final state
curl -s "$SPACE_URL/state" -H "X-Session-Id: $SESSION_ID"
