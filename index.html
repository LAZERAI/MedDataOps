    API Endpoints

    POST /reset

    Start or restart an episode. Optional body: {"task_id":"triage_report"}.

    POST /step

    Send an action: {"action_type":"run_query","parameters":{"query":"SELECT 1"}}.

    GET /state

    Get full current session state for the active episode.

    GET /health

    Returns platform health payload with API version.

    GET /tasks

    List all available tasks with metadata and hints.

    Try It with curl

    # Set your Space URL first
export SPACE_URL="https://<your-space-name>.hf.space"

# 1) health
curl -s "$SPACE_URL/health"

# 2) tasks
curl -s "$SPACE_URL/tasks"

# 3) reset (save session id)
SESSION_ID=$(curl -si -X POST "$SPACE_URL/reset" \
  -H "Content-Type: application/json" \
  -d '{"task_id":"triage_report"}' | sed -n 's/^X-Session-Id: //p' | tr -d '\r')

# 4) step
curl -s -X POST "$SPACE_URL/step" \
  -H "Content-Type: application/json" \
  -H "X-Session-Id: $SESSION_ID" \
  -d '{"action_type":"submit","parameters":{}}'

# 5) state
curl -s "$SPACE_URL/state" -H "X-Session-Id: $SESSION_ID"
